📖 Lectura teórica

1. Redes y comunicación

Una red conecta dispositivos para intercambiar datos y compartir servicios. Un equipo puede utilizar una interfaz Ethernet cableada, Wi-Fi inalámbrica o Bluetooth de corto alcance. Estar conectado a una red local no garantiza por sí solo tener acceso a Internet.

2. Ethernet

Ethernet es una familia de tecnologías de red local. En los equipos habituales se conecta mediante cable de pares trenzados y conectores 8P8C, llamados comúnmente RJ45. La velocidad negociada depende de los puertos y del cable; el enlace físico debe comprobarse antes de diagnosticar Internet.

3. Switch y router

Un switch conecta equipos dentro de una red local y reenvía tramas Ethernet según las direcciones MAC aprendidas. Un router comunica redes diferentes y suele proporcionar acceso a Internet. En redes domésticas un mismo aparato puede integrar router, switch y punto de acceso Wi-Fi.

4. Direcciones IP

La dirección IP identifica una interfaz en una red IP. Una máscara o prefijo indica la parte de red; la puerta de enlace predeterminada permite llegar a otras redes. DHCP puede asignar automáticamente direcciones, puerta de enlace y servidores DNS.

5. DNS

El sistema DNS traduce nombres de dominio a direcciones IP mediante consultas. Un equipo puede alcanzar una dirección IP y, aun así, fallar al abrir una página por su nombre si hay problemas de resolución DNS. La resolución de nombres no equivale a comprobar toda la conectividad.

6. Wi-Fi

Wi-Fi es una tecnología de red inalámbrica basada en estándares IEEE 802.11. Un dispositivo se conecta a un punto de acceso y normalmente identifica la red por su SSID. Las bandas de 2,4, 5 y 6 GHz tienen distintas características y disponibilidad según equipo y normativa.

7. Señal e interferencias

La intensidad de señal, la distancia, los obstáculos, la congestión y las interferencias afectan a la conexión Wi-Fi. Una señal fuerte no garantiza una gran velocidad. Para comparar resultados hay que medir con la misma tarea y condiciones parecidas.

8. Seguridad inalámbrica

Las redes Wi-Fi pueden utilizar WPA2 o WPA3 para proteger la autenticación y el tráfico inalámbrico. Se debe utilizar únicamente una red autorizada, no compartir credenciales y evitar cambiar la configuración de los puntos de acceso del centro.

9. Bluetooth

Bluetooth permite comunicación inalámbrica de corto alcance entre dispositivos compatibles, como teclados, ratones y auriculares. El emparejamiento establece una relación de confianza entre dispositivos; no significa necesariamente que estén conectados en ese momento.

10. Emparejado frente a conectado

Un teclado Bluetooth puede aparecer como emparejado y estar desconectado, apagado o sin batería. Para comprobarlo se revisa el estado de conexión y se escribe una frase en un editor. Una prueba funcional confirma más que la mera presencia del nombre del dispositivo.

11. Herramientas de comprobación

En Windows, ipconfig muestra configuración IP y ping permite probar respuestas ICMP cuando no están bloqueadas. En Linux, ip addr e ip route consultan direcciones y rutas. Que ping falle no demuestra por sí solo una avería, porque puede estar filtrado.

12. Diagnóstico ordenado

Se registra el síntoma, se comprueba alimentación y enlace, después IP, puerta de enlace y DNS, y finalmente el servicio deseado. En Bluetooth se revisan batería, emparejamiento, conexión activa y prueba real. Se anotan evidencias sin alterar la red corporativa.

🔧 Práctica de laboratorio

Objetivo: verificar comunicación Ethernet, Wi-Fi y Bluetooth utilizando únicamente dispositivos y redes autorizados. No cambies parámetros de la red corporativa.

  1. Comprueba si el equipo está conectado por Ethernet o Wi-Fi y registra el estado.
  2. En Windows ejecuta ipconfig; en Linux, ip addr. Anota la dirección IP y la puerta de enlace, sin publicar estos datos.
  3. Comprueba el acceso a un servicio autorizado del centro. Si se permite, realiza un ping a un destino indicado por el profesor e interpreta el resultado con cautela.
  4. Consulta el SSID de la red Wi-Fi autorizada y describe si la señal y la conexión son estables.
  5. Empareja un teclado Bluetooth de prácticas si está autorizado; después comprueba su conexión escribiendo una frase.
  6. Documenta un síntoma, una hipótesis, la prueba realizada y el resultado.

Ficha de comprobación

Casos guiados

A. Un equipo tiene enlace Ethernet, pero no abre páginas por su nombre. Explica cómo diferenciar conectividad IP y resolución DNS.

B. Un teclado Bluetooth figura como «Emparejado», pero no escribe. Propón tres comprobaciones y una prueba funcional.

C. La señal Wi-Fi es fuerte, pero la transferencia es lenta. ¿Qué factores adicionales revisarías?
