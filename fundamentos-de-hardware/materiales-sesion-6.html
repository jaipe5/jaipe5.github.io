INDICA VERDADERO O FALSO Tema: Bus

Escribe V o F. Corrige las afirmaciones falsas.

Un bus permite intercambiar información entre componentes.

Una interfaz es únicamente la forma exterior de un conector.

USB-C indica por sí solo la velocidad de transferencia.

El controlador hardware es un circuito que gestiona la comunicación.

El driver es el cable que conecta un dispositivo.

Un dispositivo correctamente conectado puede presentar problemas por falta de un driver adecuado.

PCIe se utiliza exclusivamente para tarjetas gráficas.

La expresión PCIe x4 indica cuatro carriles.

Una ranura físicamente larga siempre tiene todos sus carriles conectados.

A igualdad de generación y condiciones, más carriles permiten mayor capacidad de transferencia.

El cable SATA de datos proporciona toda la alimentación que necesita un disco de 3,5 pulgadas.

Un SSD SATA de 2,5 pulgadas puede necesitar una conexión de datos y otra de alimentación.

USB puede transportar datos y suministrar alimentación.

Todos los dispositivos USB funcionan sin ninguna alimentación eléctrica adicional.

USB-A y USB-C son tipos de conectores.

No existen conexiones USB internas.

Todos los SSD M.2 utilizan SATA.

Un SSD M.2 puede utilizar PCIe si el modelo y el equipo son compatibles.

Para elaborar un mapa basta con escribir el nombre de los dispositivos.

NVMe y M.2 no significan lo mismo.
