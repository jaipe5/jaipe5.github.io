13 · Configuración con UEFI y utilidades del sistema

📖 Lectura teórica

1. UEFI (Unified Extensible Firmware Interface) es el firmware que inicializa el hardware y prepara el arranque del sistema operativo. Sustituye en muchos equipos al BIOS tradicional. Su configuración se almacena en memoria no volátil, y la placa dispone de mecanismos para conservar los ajustes. UEFI no es Windows ni una aplicación instalada en el SSD.

2. Al encender el equipo, el firmware realiza comprobaciones de inicialización y POST, detecta dispositivos y localiza una opción de arranque válida. En su interfaz de configuración suelen aparecer el procesador, la memoria RAM, las unidades de almacenamiento, ventiladores y temperaturas. Las opciones concretas varían entre fabricantes y modelos.

3. Para entrar en la configuración UEFI suele pulsarse Supr, F2 u otra tecla indicada al iniciar el equipo. En algunos sistemas se puede acceder desde las opciones de recuperación y arranque avanzado. El menú de configuración permite consultar y modificar parámetros; el menú de arranque puntual permite elegir un dispositivo solo para ese inicio.

4. El orden de arranque establece la prioridad de las opciones disponibles. En sistemas UEFI puede aparecer Windows Boot Manager u otro gestor de arranque, en lugar de únicamente el nombre físico del SSD. Cambiar permanentemente el orden no es necesario para arrancar una sola vez desde una memoria USB.

5. El arranque desde USB requiere que el dispositivo contenga un medio de arranque preparado y que sea compatible con la configuración del equipo. Que la memoria aparezca en el menú no garantiza que pueda iniciar un sistema. Si falla, se revisan el medio, el modo de arranque y las restricciones de seguridad, sin desactivar protecciones de forma indiscriminada.

6. Secure Boot es un mecanismo de UEFI que verifica firmas de componentes del proceso de arranque conforme a la política y claves configuradas. Ayuda a impedir la ejecución de cargadores no autorizados. No equivale a cifrado de disco y no debe desactivarse sin autorización y justificación.

7. TPM (Trusted Platform Module) es un componente o función de seguridad que protege operaciones y claves criptográficas. Puede ser físico o estar implementado mediante firmware según la plataforma. Su presencia no significa que todos los datos estén cifrados automáticamente.

8. Las opciones de virtualización por hardware, como Intel VT-x o AMD-V, pueden aparecer en UEFI. Activarlas permite utilizar determinadas funciones de virtualización, pero también deben comprobarse los requisitos del sistema operativo y del hipervisor. No todos los parámetros se deben modificar en un equipo compartido.

9. Las utilidades del sistema permiten comprobar el resultado del arranque. En Windows, Información del sistema (msinfo32) muestra datos como modo BIOS y estado de arranque seguro cuando están disponibles. Administración de discos permite identificar unidades y particiones. En Linux pueden utilizarse comandos como lsblk y, si está disponible, efibootmgr para consultar opciones UEFI.

10. Antes de cambiar un parámetro se registra el valor inicial, el motivo del cambio y el resultado esperado. Se modifica un solo ajuste autorizado, se guarda según el procedimiento del fabricante y se reinicia para comprobar el efecto. Si el equipo no arranca correctamente, se restaura el valor anterior siguiendo el procedimiento aprobado.

11. Actualizar el firmware UEFI no es una tarea rutinaria sin riesgos. Debe hacerse únicamente con el archivo y método correctos para el modelo exacto de placa o equipo, siguiendo las instrucciones del fabricante y con alimentación estable. Una interrupción o un archivo incorrecto puede impedir el arranque.

12. Ejemplo: para probar una memoria USB de instalación, se conecta el dispositivo, se abre el menú puntual de arranque y se selecciona su entrada. Se comprueba que arranca el entorno previsto sin instalar ni borrar nada. Después se reinicia normalmente y se verifica que el orden permanente de arranque no ha cambiado.

🔧 Práctica guiada y registro de cambios

1. Identificar equipo→2. Consultar UEFI→3. Registrar valor inicial→4. Modificar ajuste autorizado→5. Guardar y verificar

Norma: no cambies Secure Boot, TPM, claves, voltajes ni orden permanente sin autorización. No actualices el firmware durante esta práctica.

Ficha de observación

Caso de aula

Una memoria USB aparece en el menú puntual de arranque. Explica cómo probarla sin modificar permanentemente la prioridad. Distingue «detectado» de «arrancable» y describe cómo comprobar que el equipo sigue arrancando desde su unidad habitual.

8. Cualquier USB conectado puede arrancar un sistema.

12. TPM puede ayudar a proteger claves criptográficas.

14. La virtualización por hardware puede configurarse en UEFI.
